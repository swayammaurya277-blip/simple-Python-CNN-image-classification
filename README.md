# 🧠 CNN Image Classification using Python

This project is an **image classification system built using Python, TensorFlow, and Convolutional Neural Networks (CNN)**. The model is trained using the **CIFAR-10 dataset**, which contains thousands of images belonging to 10 different categories such as airplanes, automobiles, birds, cats, dogs, horses, ships, and trucks.

The CNN automatically learns important visual features from images, including **edges, shapes, textures, and patterns**. The images are first normalized and then passed through multiple convolutional and pooling layers. After extracting useful features, the data is flattened and passed through dense layers to predict the final image category.

### 🚀 Features

* Uses a CNN architecture for image classification
* Trains on the CIFAR-10 dataset
* Image normalization and preprocessing
* Model training with validation
* Accuracy evaluation on test data
* Predicts the category of new images

### 🛠️ Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* CNN
* CIFAR-10 Dataset

### 🎯 Objective

The main objective of this project is to demonstrate how **deep learning and CNNs can be used for automatic image classification**. It is also useful for learning the fundamentals of computer vision and neural networks.

This project can be further improved by adding **custom datasets, data augmentation, a graphical user interface, model saving/loading, and real-time image prediction**.
